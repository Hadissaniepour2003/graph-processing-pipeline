Four algorithms. Two kinds of partition.

Cut fraction measures cross-partition edges for vertex algorithms. Replication measures average copies per active vertex for edge algorithms. Max/ideal load is 1.0 for equal load; larger means more imbalance. These metrics have different meanings, so there is no automatic “winner”.
